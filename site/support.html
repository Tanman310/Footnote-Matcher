How to use Footnote Matcher

The README explains every menu item and setting. The basics:

  1. Format one footnote the way you want all of them to look.
  2. Click inside that footnote.
  3. Choose Extensions → Footnote Matcher → Match all footnotes to selection.

Common questions

Nothing changed, and a message says "Footnotes already match". Every footnote already had the formatting, so there was nothing to change.

A message says "Click inside a footnote". Match copies formatting from a footnote. Click inside the footnote you want to copy, then try again. To copy from body text instead, turn on Allow matching from body text in Settings.

A footnote I added in suggesting mode wasn't changed. Google Docs doesn't let add-ons see suggested content. Accept the suggestion, then choose Reapply footnote style.

My footnotes lost their own fonts or indents. Use Edit → Undo, then open Settings and turn off the kinds of formatting you want footnotes to keep before matching again.

I don't see the Footnote Matcher menu. Reload the document. If it still doesn't appear, check Extensions → Add-ons → Manage add-ons to make sure Footnote Matcher is installed and turned on for this document.

Report a problem or suggest an idea

If you have a GitHub account, open an issue on the project's GitHub page. Search the existing issues first, in case it's already been reported.

If you don't have a GitHub account, email footnote-matcher@miller310.com.

Please describe what you did, what you expected, and what happened, and include your browser. Don't share private or sensitive documents. If an example helps, make a copy with placeholder text.

Footnote Matcher is maintained by one volunteer, so replies usually come within two weeks.

Security problems

Please don't report security problems in a public issue. Follow the steps in the project's security policy instead.
