Privacy policy

Last updated: November 26, 2026

This policy describes what the Footnote Matcher add-on for Google Docs does with your information. Footnote Matcher is made by Marcus Miller. In short: it only works on the document you have open, it stores your footnote style and settings inside that document, and it doesn't send your data anywhere.

What Footnote Matcher can access

When you install Footnote Matcher, Google asks you to allow two permissions:

  • View and manage documents that this application has been installed in (documents.currentonly). Footnote Matcher uses this only on the document where you run it, to read the formatting at your cursor and change the formatting of that document's footnotes. It can't open your other documents or files.
  • Display and run third-party web content in prompts and sidebars inside Google applications (script.container.ui). Footnote Matcher uses this to add its menu and show its messages and Settings dialog.

Footnote Matcher doesn't ask for your name, email address, contacts, or any other information about your Google Account.

What Footnote Matcher stores

Footnote Matcher stores three things, all inside the document you use it in (in that document's add-on storage, which Google calls document properties):

  • the formatting of your last match, so Reapply footnote style can use it again
  • your saved style, if you save one
  • your choices in the Settings dialog

These are formatting values, such as a font name, a size, or a color. They never include the text of your document. They stay with that document, and only Footnote Matcher can read them.

What Footnote Matcher doesn't do

  • It doesn't send your document's content or any other data to the developer or to anyone else. Its code makes no network requests.
  • It doesn't collect analytics, use cookies, track you, or show ads.
  • It doesn't sell, rent, or share any data, and doesn't use any data for advertising or to train AI models.

The Settings dialog loads Google's standard stylesheet for add-ons from ssl.gstatic.com, which is part of how Google Docs displays add-on dialogs.

Error logs

If something goes wrong while Footnote Matcher runs, Google Apps Script records the error message in the developer's Google Cloud error logs, as it does for every Apps Script add-on. Footnote Matcher's error messages describe what failed (for example, that a footnote couldn't be read). They don't include the text of your document. The developer uses these logs only to find and fix bugs.

Google API Services User Data Policy

Footnote Matcher's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

This website is hosted by GitHub Pages. It has no analytics or cookies. GitHub may log visitors' IP addresses for security, as described in GitHub's privacy statement.

Children

Footnote Matcher doesn't knowingly collect personal information from anyone, including children.
