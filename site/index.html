Make every footnote in a Google Doc look the same

Footnote Matcher is a free, open-source add-on for Google Docs. Format one footnote the way you want, and it applies that formatting to every footnote in the document in one click.

Footnote Matcher is being prepared for the Google Workspace Marketplace. Until it's listed there, you can run it from its source code by following the setup steps in CONTRIBUTING.md.

How it works

  1. Format one footnote the way you want all of them to look.
  2. Click inside that footnote.
  3. Choose Extensions → Footnote Matcher → Match all footnotes to selection.
  4. When you add more footnotes later, choose Reapply footnote style.

Footnote Matcher copies the font, size, text color, highlight, underline, strikethrough, link styling, line spacing, space before and after, alignment, and indents. Italicized titles, bold text, links, and lists inside footnotes are kept. If every footnote already matches, nothing changes and a short message says so.

More ways to use it

  • Only some footnotes: select body text that includes their footnote numbers, or click inside one footnote, and choose Reapply to selected footnote.
  • Saved style: keep a style you can return to after experimenting with Save selection as saved style and Apply saved style.
  • Settings: turn off any kind of formatting you want footnotes to keep, such as their own font or indents. Settings are saved in each document.

The README describes every menu item and setting.

Your documents stay yours

Footnote Matcher only works on the document you have open. It doesn't send your data anywhere, doesn't collect analytics, and stores only your footnote style and settings, inside that document. The privacy policy has the details.

Free and open source

Footnote Matcher is free, with no ads or paid features. Its code is public on GitHub under the GNU Affero General Public License v3.0 or later, so anyone can check what it does. It's made by Marcus Miller and was inspired by David Thorn's Footnote Style add-on, which is no longer available.

If Footnote Matcher saves you time, you can support its development. It's always optional, and the add-on stays free either way.
